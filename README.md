# zorkz.net

The source of the zorkz.net website: a static page with no build step.

## Quick start

You need git and Python 3.

1. Get the site and serve it locally:

   ```
   git clone https://github.com/aclater/zorkz.net.git
   cd zorkz.net
   python3 -m http.server 18080 --bind 127.0.0.1
   ```

2. Open http://127.0.0.1:18080/. Press Ctrl+C to stop the server.
